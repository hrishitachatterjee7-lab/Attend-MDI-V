Connect Supabase so your attendance syncs across your iPhone, second phone, and laptop automatically.

  1. Go to supabase.com → New project (skip org, it's optional)
  2. Once ready: Settings → API → copy Project URL and anon public key
  3. Go to SQL Editor → New query → paste and run this:
    CREATE TABLE IF NOT EXISTS attendance (id TEXT PRIMARY KEY, data JSONB);
